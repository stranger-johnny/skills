# TODO 人が読むためのスキル名

TODO このスキルが何をするかを、初めて読む人に向けて1〜3文で書きます。

## クイックスタート

TODO よくある依頼を処理する手順か、最小のコード例を書きます。

```bash
python scripts/todo.py input.txt
```

## ワークフロー

次のチェックリストをコピーして、終わった項目に印を付けてください。

```text
- [ ] Step 1: TODO
- [ ] Step 2: TODO
- [ ] Step 3: 結果を検証する
```

### Step 1: TODO

TODO この手順で行うことと、その理由を書きます。

### Step 2: TODO

TODO

### Step 3: 結果を検証する

TODO 結果を確かめる方法を書きます。
検証に失敗した場合に、どのステップに戻るかも書きます。

## 詳細資料

TODO 必要なときだけ読むファイルを、読む場面と一緒に並べます。
